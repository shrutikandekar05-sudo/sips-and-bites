# The Sips And Bites

A simple static cafe website with menu, gallery, and contact sections.

## Share publicly

To publish this site publicly using GitHub Pages:

1. Create a new repository on GitHub.
2. Add these files to the repository:
   - `index.html`
   - `style.css`
   - `images/`
3. Push the repository to GitHub.
4. In the repository settings, enable GitHub Pages from the `main` branch (or `gh-pages` branch).
5. The site will be available at `https://<your-username>.github.io/<repo-name>/`.
